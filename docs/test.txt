핵심 설계 포인트
항목	구현 내용
구형 필드 수렴	security_mechanism: list[str] → list[MechanismIn], code_examples: list[dict] flat → 첫 번째 Mechanism 귀속
Alias 중복 방지	find_master_by_alias() → fulltext 인덱스 선처리 → 기존 마스터 name으로 MERGE 수렴
APOC 동적 라벨	domains: ["security","performance"] → apoc.create.addLabels(c, ["Security","Performance"])
CodeExample unq_id	{mech}_{lang}_{lang_ver}_{fw}_{fw_ver} 복합 고유키로 버전별 독립 증분
연쇄 삭제	delete_concept → 고아 Mechanism·CodeExample 탐지 후 DETACH DELETE
교차 도메인	ConnPoolExhaustion, MemoryLeak → domains: ["performance","security"] → :Concept:Security:Performance
멱등성	ON CONFLICT DO UPDATE (PG) + MERGE ON MATCH SET (Neo4j) — 반복 실행 안전
