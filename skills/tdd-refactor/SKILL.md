# Skill: tdd-refactor

## 트리거 조건

"리팩토링해줘", "Refactor 단계 진행", "코드 개선해줘 (테스트 유지)" 등의 요청이 들어올 때

## 역할

모든 테스트가 PASSED인 상태에서 구현 코드의 중복 제거, 명명 개선, 타입 힌트 추가 등을 수행합니다.

## 입력

- `<모듈명>.py` — Green 상태의 구현 파일
- `test_<모듈명>.py` — 통과 중인 테스트 파일

## 출력

- `<모듈명>.py` — 개선된 구현 코드 (pytest 실행 시 여전히 전부 PASSED)

## 제약사항

- 리팩토링 전/후 pytest가 모두 PASSED여야 함
- 새로운 기능 추가 금지
- `test_*.py` 파일 절대 수정 금지
- 변경 단위를 작게 유지하고, 각 변경 후 즉시 pytest 실행
- 실패 발생 시 즉시 마지막 변경 롤백

## 개선 항목 우선순위

1. 중복 코드 제거
2. 함수/변수명 명확화
3. 타입 힌트 추가
4. 매직 넘버/문자열 상수 추출

## 예시

입력: todo.py (Green, 중복 로직 있음)  
출력: todo.py (중복 제거 + 타입 힌트 추가) → pytest 전부 PASSED 유지
