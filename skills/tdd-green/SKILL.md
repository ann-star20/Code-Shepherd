# Skill: tdd-green

## 트리거 조건

"테스트 통과시켜줘", "Green 단계 진행", "구현해줘 (TDD)" 등의 요청이 들어올 때

## 역할

현재 FAILED 상태인 테스트를 모두 읽고, 각 테스트를 통과시키는 최소한의 구현 코드를 작성합니다.

## 입력

- `test_<모듈명>.py` — 현재 FAILED 상태의 테스트 파일
- `<모듈명>.py` — 빈 껍데기 파일

## 출력

- `<모듈명>.py` — 모든 테스트를 통과하는 구현 코드 (pytest 실행 시 전부 PASSED)

## 제약사항

- 테스트를 통과하는 가장 단순한 코드만 작성 (함수 하나 5줄 이내 권장)
- 클래스, 추상화, 디자인 패턴 미리 도입 금지
- `test_*.py` 파일 절대 수정 금지
- 구현 완료 후 pytest를 실행하여 전부 PASSED 확인

## 예시

입력: test_todo.py (2 failed)  
출력: todo.py (최소 구현) → pytest 실행 → 2 passed
