# 🎤 발표자용 — 이슈 검출 + 집계 설명 (Dev3 + pr-comment)

> 이 문서만 읽으면 발표 가능. 위에서 아래로 읽으면 그대로 발표 흐름.

---

## 한 문장 오프닝

> "신입이 짠 코드를 검사해서 문제를 찾아내고(검출), 그 문제들을 모아서
> '통과냐 재작업이냐 긴급이냐' 자동 판정(집계)하는 흐름을 보여드릴게요."

---

## 1️⃣ 이슈 검출 — 코드에서 문제 찾기

**한 줄**: 코드를 검사해서 **테스트·성능 문제**를 찾아냄.

**찾는 것 두 갈래**:
- 🧪 테스트가 충분한가 — 커버리지(테스트가 코드 몇 %를 확인했나), 테스트 없는 함수
- ⚡ 코드가 느리진 않나 — N+1 쿼리, O(n²) 복잡도

**결과물 = 표준 JSON 데이터** (사람용 글이 아니라 시스템용 데이터):
```json
{
  "severity": "Major",            ← 심각도
  "file": "src/posts.py", "line": 7,  ← 위치
  "message": "N+1 쿼리: 루프 안에서 DB 호출 반복",  ← 내용
  "rule_id": "PERF-002",          ← 문제 종류
  "suggestion": "joinedload()로 한 번에 조회하세요"  ← 해결책
}
```

**데모 검출 결과 (5개)**:
```
🟧 TEST-001  커버리지 20% < 80%
🟨 TEST-004  get_posts 테스트 없음
🟨 TEST-004  find_dups 테스트 없음
🟧 PERF-002  N+1 쿼리 (반복문 안 DB 호출)
🟨 PERF-001  O(n²) 중첩 루프
```

🎙️ **말하기**: "검출 결과는 사람용 리포트가 아니라, 다음 단계가 바로 받아 쓸 수 있는 **표준 데이터(JSON)** 예요. 각 문제마다 심각도·위치·내용·해결책이 정해진 형식으로 담깁니다."

---

## 2️⃣ 이슈 집계 + 판정 — 모아서 등급 매기기

**한 줄**: 찾은 문제를 심각도별로 세서 → 규칙으로 → **한 단어로 자동 판정**.

**판정 규칙**:
```
Critical(치명적) 1개 이상  → escalate (긴급, 시니어 즉시 호출)
Major(중요) 3개 이상       → rework (재작업)
그 외                      → lgtm (통과)
```

**데모 판정 결과**:
```
집계: Critical 0 · Major 2 · Minor 3
   ↓
판정: lgtm (통과)   ← Major 2개라 3개 미만 → 통과
```

🎙️ **말하기**: "문제를 심각도별로 센 다음 정해진 규칙으로 자동 판정해요. 치명적 문제가 있으면 시니어를 즉시 부르고, 중요 문제 3개 넘으면 재작업, 그 외엔 통과. 데모는 Major 2개라 '통과' 나왔습니다."

---

## 3️⃣ 데모 실행 — 라이브로 보여주기

**터미널에서**:
```powershell
cd pr-comment-agent
py integration_demo.py
```

→ 화면에 단계가 쭉 뜸:
```
[1] Dev3 검출      → 5 이슈, 커버리지 20%
[2] 집계·판정       → verdict=lgtm
[3] 코멘트 생성     → 신입이 받을 피드백 텍스트
[4] GitHub 등록     → (dry-run) 파일로 저장
```

🎙️ **말하기**: "검출부터 코멘트 작성까지 한 흐름으로 자동으로 돕니다."

---

## ⚠️ 정직하게 말해야 할 3가지 (질문 대비)

| 질문 | 답 |
|---|---|
| "데모는 가짜 아니에요?" | "**입력만** 미리 준비한 샘플이고, **검출·판정 엔진은 진짜**예요. 실제 PR 넣어도 똑같이 작동합니다. (= 자동차를 시험대에서 돌리는 것. 엔진은 진짜)" |
| "진짜 GitHub에 올라가요?" | "코멘트 텍스트까지 진짜로 만들어요. GitHub **실제 등록은 토큰만 연결하면** 바로 됩니다. 지금은 데모라 파일 저장(dry-run)으로 보여드려요." |
| "판정 다음 행동은요?" | "판정 + 코멘트 작성까지 했고, 실제 등록·Slack 알림은 **준비됐지만 키 연결 + 통합 단계**예요. 후속 행동(시니어 승인 등)은 다른 모듈 영역입니다." |

---

## 📌 발표자가 외울 핵심 3줄

```
1. 검출:  코드에서 테스트·성능 문제를 찾아 표준 JSON으로 (심각도·위치·해결책)
2. 집계:  심각도별 개수 → 규칙 → 한 단어 판정 (통과 lgtm / 재작업 rework / 긴급 escalate)
3. 데모:  입력만 샘플, 엔진은 진짜. integration_demo.py 하나로 검출→판정→코멘트 시연
```
