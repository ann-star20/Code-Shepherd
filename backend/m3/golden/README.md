# golden/ — 골든셋 (게이트 1: 라벨 확정 후 수정 금지)

> **이 디렉토리는 정현의 라벨 전수 확인 후 동결된다. eval 실패 시 코드를 고친다 — 골든셋을 고치지 않는다.**
> 라벨 변경/추가/삭제는 [결정요청] + 명시적 승인 필수.

## 구조 (브리프 §4.1)

```
golden/
  pr_001/
    diff.patch        # unified diff
    files/            # 변경 파일 전문 (diff 적용 후 상태)
    label.yaml        # contracts/README.md 의 GoldenLabel 스키마
```
