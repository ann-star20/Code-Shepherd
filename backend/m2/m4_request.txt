2.
보안
- SQL injection
하위개념:
- . raw() 오용 — 상품 검색
- cursor.execute() 오용 — 주문 내역 조회
- extra() / RawSQL 오용 — 가격 필터
- ORDER BY 동적 정렬 — 상품 목록
- 로그인 인증 쿼리 — login_view
- 입력값 검증 부재 — 주문 ID 조회
- clickjacking
하위개념:
- XFrameOptionsMiddleware 미설정 — 전체 사이트 노출
- 결제·주문 뷰에 xframe_options_exempt 잘못 적용
- SAMEORIGIN 설정 — 자사 서비스 내 iframe 허용
- CSRF + Session Cookie SameSite 설정 누락
성능
- N+1 query
하위개념:
- ForeignKey 접근 시 N+1 — 주문 목록
- ManyToMany 접근 시 N+1 — 상품 목록
- values()와 values_list() 미활용 — 불필요한 모델 인스턴스 생성
- bulk 메서드 미사용 — 루프 내 개별 save()
- 불필요한 count() / exists() 중복 호출
- 시간복잡도
하위개념:
- 이중 반복문 (Nested Loop) — O(N²) → O(N)
- 리스트 선형 탐색 (Linear Search in List) — O(N) → O(1)
- O(N²) 정렬 직접 구현 — O(N²) → O(N log N)
- 정렬된 데이터 선형 탐색 — O(N) → O(log N)
- 요청마다 고비용 연산 반복 — O(N log N) → O(1)
