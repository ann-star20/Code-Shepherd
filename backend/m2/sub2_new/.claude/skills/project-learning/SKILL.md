# Project Learning Skill

## When to Use

- 새로운 기술/패턴을 프로젝트에서 처음 사용할 때
- 코드가 왜 이렇게 작성됐는지 이해하고 싶을 때
- 작업하면서 배운 것을 나중에 복습할 수 있게 기록할 때
- 개발 작업과 학습을 동시에 진행할 때
- **막힌 개념이 있을 때** — 설명 + 노트 저장까지 한 번에

> **빠른 Q&A만 원하면** → `learning-mentor` 에이전트 사용
> **설명 듣고 노트로 남기고 싶으면** → `/project-learning` 사용

## How It Works

### 1. 즉시 학습 (Just-In-Time Learning)
기술을 사용하기 직전에 15-30분 미니 학습 세션 진행.
"배우고 쓰기"가 아니라 "쓰면서 배우기" — 맥락이 있을 때 학습 효율 최고.

### 2. 4-Layer 설명 방식
모든 개념을 4단계로 설명:
1. **비유** (기술 용어 없이, 일상 언어로 — 중학생도 이해 가능)
2. **명확한 개념** (공식 정의 + 핵심 원리 — 면접·실무에서 쓸 수 있는 수준)
3. **왜 쓰나** (이 기술이 없으면 어떤 문제가 생기는지)
4. **코드** (현재 3rd-Project-sub2 프로젝트 맥락에서 실제 사용 예시)

### 3. 학습 노트 자동화
새 기술 사용 → 자동으로 `docs/learning/[영역]/[기술명].md` 생성.
해당 노트는 자동으로 복습 스케줄에 등록됨.

### 4. 코드-학습 연결
코드를 작성할 때마다 "왜 이걸 썼는가"를 1줄 코멘트로 추가 (학습용).
나중에 코드 자체가 학습 자료가 됨.

## Examples

**기술 학습:**
```
/project-learning React useEffect
→ 3-Layer 설명 + 프로젝트에서 어떻게 사용될지 + 학습 노트 자동 저장
```

**막힌 개념 해결 + 기록:**
```
/project-learning NestJS Guard가 왜 필요한지 모르겠어
→ 비유로 설명 + 3rd-Project-sub2 코드 연결 + 학습 노트 저장
```

**코드 흐름 분석:**
```
/project-learning code frontend/src/services/api.ts
→ 파일 전체 흐름 분석 + 사용된 패턴 설명 + 학습 노트 저장
```

**비교 학습:**
```
/project-learning axios vs fetch
→ 두 방법 비교 + 3rd-Project-sub2에서 어느 것을 쓸지 + 학습 노트 저장
```

## Learning Note Template

자동 생성되는 학습 노트 형식:

```markdown
# [기술명] 학습 노트

**날짜**: YYYY-MM-DD
**파일**: [관련 파일 경로]
**복습 예정**: D+1, D+3, D+7

## 한 줄 요약
[비전공자도 이해할 수 있는 한 문장]

## 왜? / 언제?
- **해결하는 문제**: ...
- **적합한 상황**: ...
- **부적합한 상황**: ...

## 코드 예시 (우리 프로젝트)
[실제 사용 코드]

## 핵심 개념 3가지
1. ...
2. ...
3. ...

## 복습 퀴즈
1. Q: ...  A: (숨김)
2. Q: ...  A: (숨김)
3. Q: ...  A: (숨김)
```

## Integration with Test Agent

학습 노트 생성 후 복습 주기 도달 시 test-agent 자동 호출:
- D+1: 핵심 키워드 퀴즈 (5분)
- D+3: 백지복습 (10분)
- D+7: 코드 작성 테스트 (15분)
