지금까지 대화한 내용에서 **비전공자 / IT 초보자** 기준으로 나중에 다시 헷갈릴 수 있는 Q&A를 추출해서 저장합니다.

## 저장 기준

아래 기준을 **모두 충족**하는 내용만 저장합니다:
- 개념이나 구조를 처음 이해한 순간
- "왜 이걸 쓰나요?", "어떻게 하나요?" 같은 방법론 질문
- 프로젝트 구조나 파일 위치 관련 질문
- 에러 해결 과정

저장하지 않는 것:
- 단순 코드 수정 요청
- 파일 읽기/쓰기만 한 작업
- 일회성 확인 작업

## 저장 형식

파일 경로: `docs/qa/YYYY-MM-DD.md`
(오늘 날짜로 자동 생성, 이미 있으면 이어서 추가)

```markdown
# Q&A 기록 — YYYY-MM-DD

> 대상: 비전공자 / IT 초보자
> 저장 기준: 앞으로 다시 헷갈릴 수 있는 내용 위주

---

## Q1. [질문 요약]

**A.** [핵심 답변 — 중학생도 이해할 수 있는 언어로]

[필요시 표, 코드 블록, 예시 추가]

---
```

## 실행 순서

1. 오늘 날짜 확인 → 파일 경로: `docs/qa/YYYY-MM-DD.md`
2. 해당 파일이 **이미 존재하면** → 기존 내용을 Read로 읽어서 마지막 Q 번호 파악
3. 대화 전체를 검토해서 저장 기준에 맞는 Q&A 목록 추출
4. 파일 존재 여부에 따라 처리:
   - **없으면**: 헤더 포함해서 새 파일 생성
   - **있으면**: 기존 파일 끝에 이어서 추가 (헤더 중복 금지, Q 번호 이어서)
5. 저장 완료 후 사용자에게 "몇 개 추가됐는지 + 파일 경로" 알림
6. `/compact` 실행 제안

## 주의사항

- 답변은 반드시 **비전공자도 이해하는 언어**로 재작성 (원본 그대로 복사 금지)
- 코드는 최소화, 개념 설명 위주
- 한 Q&A는 최대 20줄 이내로 요약
