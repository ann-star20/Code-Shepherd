## AX/DX 직무 지원 자기소개서 본문

시니어 개발자가 신입 PR 리뷰에 하루 1~2시간을 소비하면서도 SQL 인젝션·N+1 쿼리 같은 반복 실수가 줄지 않는 문제를 목격했습니다. 분석 도구는 있었지만, AI 판단과 연결해 자동화하는 레이어가 없었습니다.

저는 6인 멀티 에이전트 플랫폼 프로젝트에서 정적 분석·보안 스캔 에이전트를 단독 설계·구현했습니다. LangGraph StateGraph로 5개 노드를 연결하고, Critical 이슈가 탐지되면 실행 경로가 자동으로 에스컬레이션으로 전환되는 Agentic Workflow를 구축했습니다. Python·JavaScript·C# 등 7개 언어 분석 도구를 Pydantic 계약으로 통합하고, pgVector 기반 RAG로 과거 유사 이슈를 LLM context에 주입해 severity 판단 정확도를 높였습니다. Critical은 Claude Sonnet, Major는 Haiku, Minor는 LLM 생략으로 설계해 품질과 비용을 동시에 관리했고, LangSmith 트레이싱으로 AI 판단 전 과정을 추적 가능한 Observability 체계도 구축했습니다.

결과적으로 시니어 리뷰 부담 70% 감소를 목표로 하는 자동화 파이프라인 기반을 마련했고, BigQuery 이중 적재와 Airflow DAG로 개발자 실수 패턴의 정량 분석과 주간 리포트 자동화까지 구현했습니다.

이 경험을 통해 AI 도입은 자동화 그 자체보다, AI 판단이 업무 흐름을 제어하고 Observability와 비용 구조가 처음부터 설계될 때 실질적인 가치가 생긴다는 것을 배웠습니다. AX/DX 직무에서 AI 내재화 과제를 기획하고 실행하는 데 이 역량을 바로 기여하겠습니다.
