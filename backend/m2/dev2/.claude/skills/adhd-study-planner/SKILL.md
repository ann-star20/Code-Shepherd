# ADHD Study Planner Skill

## When to Use

- ADHD 친화적 학습 계획을 세울 때
- 마이크로태스크로 작업을 분해할 때
- 에빙하우스 복습 주기를 계산할 때
- 미완료 태스크를 재조정할 때
- 성취율이 낮을 때 전략을 재수립할 때

## How It Works

### 1. 마이크로태스크 분해 원칙
- 단위: 최대 25분 (포모도로 기반)
- 완료 판단 기준을 명확히 작성 ("읽기" X → "p.10~20 읽고 키워드 3개 적기" O)
- 휴식을 반드시 포함 (25분 작업 + 5분 휴식)

### 2. 에빙하우스 복습 주기 계산
```
학습일 D → D+1 → D+3 → D+7 → D+15 → D+30
```
각 복습 점수에 따라 다음 주기 자동 조정:
- 80점↑: 다음 주기 유지
- 60-79점: 한 단계 앞당김
- 60점↓: 내일 재복습

### 3. ADHD 도파민 보상 시스템
- 체크박스 완료 = 즉각 시각적 피드백
- 3개 연속 완료 = 미니 배지
- 하루 목표 달성 = 당일 배지
- 7일 연속 = 스트릭 배지

### 4. 계획 조정 트리거
- 성취율 < 60%: 계획 축소 권장
- 같은 태스크 3회 미완료: 태스크 재분해
- 오후 3-5시 미완료 집중: 시간대 재배치

## Examples

**기본 사용:**
"오늘 Python 기초를 2시간 공부하고 싶어" → 25분 단위 4세션으로 분해, 복습 항목 포함 계획 생성

**자격증 모드:**
"정보처리기사 필기 D-30" → 과목별 중요도 가중 계획, 모의고사 포함 30일 플랜

**복습 모드:**
"오늘 복습할 게 뭐야?" → 에빙하우스 주기 기준 오늘 복습 필요 항목 우선순위 목록

## Output Format

```markdown
## 오늘의 학습 플랜 — [날짜]

**총 가용 시간**: X시간
**목표 태스크**: X개

### 오전 블록 [09:00 - 11:00]
- [ ] (25분) [태스크명] → 완료 기준: [구체적 행동]
- 🔄 (5분) 휴식
- [ ] (25분) [태스크명] → 완료 기준: [구체적 행동]
- 🔄 (5분) 휴식
- [ ] (25분) **복습**: [항목명] (D+3)
- 🔄 (5분) 휴식
- [ ] (25분) [태스크명] → 완료 기준: [구체적 행동]

### 오후 블록 [14:00 - 16:00]
...

### 오늘의 복습 목록
| 항목 | 최초 학습 | 주기 | 복습 방법 |
|------|----------|------|---------|
| [항목] | [날짜] | D+3 | 백지복습 |

### 성취 배지 목표
- [ ] 첫 세션 완료 🌱
- [ ] 점심 전 3세션 완료 🌿
- [ ] 오늘 계획 전체 달성 🏆
```
