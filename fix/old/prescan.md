기존에 데이터베이스에 적재되어 성공적으로 완료된 프레임워크 및 버전 이력(Historical Registry)을 동적으로 쿼리하여 교차 대조하는 융합 추론 논리로 업그레이드하겠습니다.

동시에 추론 신뢰도가 낮을 경우, 프론트엔드가 대시보드(HITL)의 셀렉트 박스(Dropdown)에 바로 뿌려줄 수 있도록 "기존 등록 프레임워크 목록"과 "해당 프레임워크의 기존 등록 버전 목록"을 검색 제안 페이로드로 함께 넘겨주어 관리자가 마우스 클릭 몇 번만으로 매핑하거나, 완전히 새로운 프레임워크를 영구 등록할 수 있도록 설계를 고도화하겠습니다.

역사적 데이터 자가 증식(Self-Learning Effect): 새로운 사이트 수집을 완료할 때마다 documents 테이블에 새로운 프레임워크와 버전 문자열이 축적됩니다. 프리스캔 엔진은 별도의 코드 배포 없이도 다음번 스캔 시 축적된 데이터(existing_frameworks)를 기반으로 동적 Fuzzy 문자열 매핑을 수행하므로 추론 정확도가 자동으로 상승합니다.

완벽한 HITL UX 바인딩: 추론 신뢰도가 낮아 manual_required 상태가 반환되면, 프론트엔드는 이 API가 반환한 suggested_frameworks 목록을 이용해 대시보드 입력 필드를 셀렉트 드롭다운(Dropdown) 형태로 채웁니다. 관리자는 손으로 입력할 필요 없이 마우스로 기존 내역을 클릭해 매핑하거나, 완전히 새로운 텍스트를 적어 새로 등록할 수 있습니다.
